# 나의 할 일 목록

HTML, CSS, JavaScript만으로 만든 간단한 할 일(To-Do) 관리 웹 앱입니다. 별도의 설치나 빌드 없이 브라우저에서 바로 실행할 수 있습니다.

## 주요 기능

- **할 일 추가**: 입력 후 `추가` 버튼을 누르거나 Enter 키를 누르면 추가됩니다.
  - 빈 내용이나 이미 등록된 할 일은 추가되지 않습니다.
- **완료 표시**: 체크박스를 눌러 완료/미완료를 전환합니다.
- **삭제**: 각 항목의 `✕` 버튼으로 삭제합니다.
- **필터**: `전체` / `진행중` / `완료` 버튼으로 원하는 항목만 볼 수 있습니다.
- **완료된 항목 삭제**: 완료된 할 일을 한 번에 지웁니다.
- **개수 표시**: `전체 N개 · 완료 N개` 형태로 현황을 보여 줍니다.
- **자동 저장**: 할 일 목록은 브라우저의 LocalStorage(`todos` 키)에 저장되어, 새로고침하거나 다시 열어도 유지됩니다.

## 실행 방법

1. 저장소를 내려받습니다.
   ```bash
   git clone https://github.com/dbsgn814-gif/my-todo-app.git
   ```
2. `index.html` 파일을 브라우저로 엽니다. 서버는 필요 없습니다.

## 파일 구성

| 파일 | 설명 |
| --- | --- |
| `index.html` | 화면 구조 (입력 폼, 필터 버튼, 목록) |
| `style.css` | 디자인 (보라색 테마, 카드형 레이아웃) |
| `main.js` | 동작 (추가·삭제·완료·필터·저장) |

## 사용 기술

- HTML5
- CSS3 (CSS 변수)
- JavaScript (외부 라이브러리 없음)
- LocalStorage
